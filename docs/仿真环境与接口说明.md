# iCAN 城市应急物资投送基础练习环境接口说明

## 启动

```bash
cd <ican_delivery_user_ws>
source scripts/setup_env.sh
bash scripts/run_delivery_env.sh
```

该脚本只启动基础仿真、飞控桥接和一个最小投放示例，不启动坐标导航、完整任务主流程、裁判系统或视觉识别节点。

## 已提供内容

| 内容 | 说明 |
| --- | --- |
| Gazebo 世界环境 | 任务二投送场地、起降点、两扇窗口、四个投放点和四个可释放物块 |
| UAV 模型 | 简化 UAV，支持速度控制、前向相机、前向 3D 雷达和下方物块托盘 |
| 传感器 | `/uav/camera/image`、`/uav/camera/camera_info`、`/uav/lidar/points`、TF 和 `/uav/odom` |
| 飞控桥接 | `/flight_control/current_pose`、`/uav/current_pose`、`/flight_control/cmd_vel` |
| 投放接口 | `/delivery/drop_cmd`、`/delivery/package_state` |
| 最小模板 | `ican_delivery_examples/minimal_drop_demo.py` |

## 基础控制接口

| 名称 | 类型 | 方向 | 说明 |
| --- | --- | --- | --- |
| `/flight_control/current_pose` | `geometry_msgs/msg/PoseStamped` | 订阅 | 飞控桥接输出的当前 UAV 位姿。 |
| `/uav/current_pose` | `geometry_msgs/msg/PoseStamped` | 订阅 | 同上，便于用户直接查看。 |
| `/flight_control/cmd_vel` | `geometry_msgs/msg/Twist` | 发布 | 推荐用户控制入口，飞控桥接会转发到底层 `/uav/cmd_vel`。 |
| `/uav/cmd_vel` | `geometry_msgs/msg/Twist` | 发布 | 底层 UAV 速度接口，使用 `linear.x/y/z` 和 `angular.z`。 |
| `/uav/odom` | `nav_msgs/msg/Odometry` | 订阅 | 底层 UAV 里程计。 |
| `/uav/camera/image` | `sensor_msgs/msg/Image` | 订阅 | UAV 前向相机图像。 |
| `/uav/camera/camera_info` | `sensor_msgs/msg/CameraInfo` | 订阅 | UAV 相机内参。 |
| `/uav/lidar/points` | `sensor_msgs/msg/PointCloud2` | 订阅 | UAV 前向 3D 点云。 |
| `/delivery/drop_cmd` | `std_msgs/msg/String` | 发布 | 投放命令，支持 `red`、`yellow`、`black`、`white`，也兼容编号 `1`、`2`、`3`、`4`。 |
| `/delivery/package_state` | `std_msgs/msg/String` | 订阅 | 物块携带/释放状态。 |

## 常用命令

```bash
ros2 topic echo /flight_control/current_pose
ros2 topic echo /uav/camera/image
ros2 topic echo /uav/lidar/points
ros2 topic echo /delivery/package_state
ros2 topic pub /flight_control/cmd_vel geometry_msgs/msg/Twist "{linear: {x: 0.0, y: 0.0, z: 0.15}, angular: {z: 0.0}}" -r 10
ros2 topic pub --once /delivery/drop_cmd std_msgs/msg/String "{data: red}"
```
