# 快速开始

## 1. 安装 ROS 2 Humble 和 Gazebo

```bash
cd <ican_delivery_user_ws>
bash scripts/00_install_ros2_gazebo.sh
```

如果系统已经安装好 ROS 2 Humble 和 Gazebo Classic，可以跳过这一步。

## 2. 解包基础环境并编译示例包

```bash
bash scripts/01_setup_delivery_user_workspace.sh
```

脚本会解包 `packages/ican_delivery_env_binary.tar.gz`，并编译 `src/ican_delivery_examples`。

## 3. 加载环境

```bash
source scripts/setup_env.sh
```

## 4. 检查环境

```bash
bash scripts/check_sim_env.sh
```

## 5. 启动练习环境

```bash
bash scripts/run_delivery_env.sh
```

脚本会打开三个终端标签：

| 终端 | 说明 |
| --- | --- |
| `delivery sim` | Gazebo 仿真场景和 RViz 传感器视图 |
| `flight control` | 飞控桥接节点 |
| `minimal example` | 最小投放示例 |

## 6. 运行用户示例

启动脚本会自动运行一次最小投放示例。也可以另开终端手动运行：

```bash
source scripts/setup_env.sh
ros2 run ican_delivery_examples minimal_drop_demo
```

示例会通过 `/flight_control/cmd_vel` 控制 UAV 原地上升、下降、投放一个物块，然后降落。
